# Personal Portfolio Website – Muhammad Abdullah Arif

## 📌 Project Overview
This is my **Personal Portfolio Website** created as part of the **Coursera Microsoft Copilot Assignment**.  
The website is built using **HTML, CSS, and JavaScript**, and deployed using **GitHub Pages**.  

The portfolio highlights:
- My introduction and skills
- Sample projects
- Contact section for communication
- A responsive layout for different devices
- Interactive elements with JavaScript

---

## 🚀 Features
- ✅ **HTML5** for semantic structure  
- ✅ **Accessible design** (alt tags, proper headings, ARIA labels)  
- ✅ **CSS3 styling** with a modern and responsive design  
- ✅ **JavaScript interactivity** (navigation toggle, smooth scrolling, button effects, etc.)  
- ✅ **Responsive** across mobile, tablet, and desktop screens

## 🛠️ Technologies Used
- HTML5
